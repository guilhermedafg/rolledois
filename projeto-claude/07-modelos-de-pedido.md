# Modelos de pedido

Copie, preencha o que está entre < > e mande no projeto.

## Ideias de conteúdo
```
Me dá <10> ideias de posts para <pilar / objetivo>, para as próximas <2 semanas>.
Para cada uma: formato, gancho, por que funciona, esforço de produção (baixo/médio/alto).
Antes de detalhar, me pergunte o que precisar.
```

## Roteiro de Reels
```
Roteiro de Reels sobre <tema/pessoa/lugar>, de <30-45>s.
Material que eu tenho ou consigo gravar: <descrever>.
Quero: gancho, falas ou texto na tela por cena, takes sugeridos, CTA e legenda.
Me dê 2 opções de gancho.
```

## Carrossel
```
Carrossel de <N> slides sobre <tema>.
Objetivo: <salvamento / compartilhamento / trazer criador>.
Quero o texto de cada slide, sugestão visual por slide e legenda.
```

## Campanha
```
Quero uma campanha para <objetivo, ex.: trazer os 10 primeiros criadores>.
Prazo: <X semanas>. Orçamento: <R$ ou zero>.
Me traga 2 ou 3 conceitos com prós e contras e recomende um. Não detalhe antes da minha escolha.
```

## Calendário
```
Monte o calendário de <mês>, com <1-2> posts por semana, seguindo a proporção de pilares.
Tabela: data, pilar, formato, tema, gancho, status.
```

## Abordagem de criador
```
Escreva uma DM para convidar <@criador> para o Rolle.
O que sei dele: <nicho, estilo, lugares que recomenda>.
Tom: <mais formal / mais próximo>. Curta, sem parecer spam. Me dê 2 versões.
```

## Revisão de tom
```
Revise este texto no tom de voz do Rolle e aponte o que mudou e por quê:
<texto>
```

## Análise de dados (Mixpanel)
```
Segue exportação do Mixpanel de <período>: <anexo/cole os dados>.
Pergunta que quero responder: <ex.: de onde vêm os usuários que voltam?>
Quero: o que os dados dizem, o que provavelmente significa, o que fazer, e as limitações.
```

## Estratégia
```
Preciso decidir <decisão>. Contexto: <…>.
Me dê as opções, os trade-offs, sua recomendação e o que precisaria ser verdade para ela dar certo.
```

## Registrar decisão
```
Resuma o que decidimos nesta conversa no formato do 09-decisoes-e-pendencias.md.
```
